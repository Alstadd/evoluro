# evoluro

Evoluro — roguelite dungeon-crawler с пошаговыми боями в духе monster-collector RPG. Игрок собирает команду существ, развивает их через три стадии, ловит новых союзников Камнями душ, экспериментирует с сигилами и бридингом, а долгосрочную мета-прогрессию получает через мистические яйца вместо платных гача-механик.

## Документы и данные

- `docs/first_dungeon_system_data.md` — подробная дизайн-спецификация первого данжа: сигилы, редкости, яйца, комнаты, боевая система, бридинг и таблицы существ.
- `data/first_dungeon_system_data.json` — машинно-читаемый стартовый справочник для будущей реализации систем первого данжа.
